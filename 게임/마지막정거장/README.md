# 마지막 정거장 — 프로토타입

시간 반복형 2D 추리 어드벤처의 웹 프로토타입입니다.

## 실행

`index.html`을 브라우저로 열면 실행됩니다. 설치나 서버는 필요하지 않습니다.

## 조작

- `WASD` 또는 방향키: 이동
- `E` 또는 `Space`: 주변 인물·물건 조사
- `R`: 시간을 되돌려 다음 반복으로 이동

## 진행 순서

1. 학생과 대화해 자판기 아래의 열쇠 정보를 얻습니다.
2. `R`로 시간을 되돌립니다.
3. 자판기에서 분실물 보관함 열쇠를 찾습니다.
4. 보관함에서 역무실 열쇠를 찾습니다.
5. 역무실 근처의 CCTV 화면을 조사해 첫 프로토타입을 완료합니다.
